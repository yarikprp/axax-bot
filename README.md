# AVAX Trading & Analytics Signal Bot 🚀

Автоматизированный торговый и аналитический бот для мониторинга рынка криптовалюты **Avalanche (AVAX)**. Бот отслеживает деривативный рынок на бирже **Bybit** (пара `AVAX/USDT:USDT`), проводит глубокий технический анализ ценового действия и метрик ликвидности, верифицирует активность с помощью ончейн-данных сети Avalanche и присылает готовые сигналы на открытие позиций (LONG/SHORT) в Telegram.

---

## 📌 Зачем нужен этот продукт?

На криптовалютном рынке стратегии, основанные исключительно на базовых графических индикаторах, часто дают ложные сигналы из-за высокой волатильности и манипуляций ликвидностью со стороны крупных участников.

**Этот бот решает эту проблему за счет трехуровневой фильтрации рыночных данных:**

1. **Технический анализ ценового действия (Price Action & Ликвидность):**
   - Алгоритм отслеживает снятие локальной ликвидности — выходы за пределы экстремумов последних периодов (`rolling_low` / `rolling_high`) с последующим закрытием свечи в противоположную сторону (ложный пробой/свип ликвидности).
2. **Анализ деривативных метрик (Open Interest & Funding Rate):**
   - **Открытый интерес (OI):** сигнал подтверждается только тогда, когда текущий OI превышает скользящее среднее (`oi_average`), что указывает на приток нового капитала в позицию.
   - **Ставка финансирования (Funding Rate):** фильтрует перегретый рынок, предотвращая лонги при слишком высокой ставке и шорты при отрицательной/низкой ставке.
3. **Ончейн-фильтрация (On-Chain Activity через Snowtrace):**
   - Сигнал не будет отправлен, если в блокчейне Avalanche C-Chain не зафиксирована активность крупных игроков («китов») — транзакций смарт-контракта Wrapped AVAX (WAVAX) объемом от 10 000 AVAX за последние 24 часа.
4. **Управление рисками (Risk Management):**
   - Для каждого сигнала автоматически рассчитываются уровни:
     - **Вход (Entry Price):** цена закрытия свечи.
     - **Стоп-лосс (Stop Loss):** локальный экстремум сигнальной свечи.
     - **Тейк-профит (Take Profit):** рассчитывается с фиксированным коэффициентом Risk/Reward (по умолчанию 1:2).
5. **Оповещения и прозрачность:**
   - Моментальная отправка сигналов и уведомлений об ошибках в Telegram.
   - Сердцебиение (Heartbeat) каждые 6 часов («❤️ Бот работает»), подтверждающее бесперебойную работу сервиса.
   - Автоматическая запись истории всех сработавших сигналов в файл `trade_history.csv`.

## 📂 Структура проекта

```text
avax_bot/
├── .env.example          # Пример файла с переменными окружения
├── .dockerignore         # Исключения для сборки Docker-образа
├── Dockerfile            # Инструкция сборки легковесного контейнера с ботом
├── docker-compose.yml    # Конфигурация для запуска бота через Docker Compose
├── requirements.txt      # Зависимости Python (ccxt, pandas, requests, python-dotenv)
├── config.py             # Центральный конфигурационный файл параметров стратегии и API
├── main.py               # Главный цикл мониторинга и координации работы
├── strategy.py           # Логика расчета индикаторов и определение сигналов LONG/SHORT
├── bybit_service.py      # Модуль взаимодействия с Bybit API (OHLCV, OI, Funding Rate)
├── onchain_service.py    # Модуль проверки ончейн-транзакций китов через Snowtrace API
├── telegram_service.py   # Модуль отправки сообщений в Telegram
├── logger.py             # Логирование сформированных торговых сигналов в CSV
└── trade_history.csv     # Файл истории сигналов (создается автоматически)
```

## ⚙️ Настройка окружения (`.env`)

Перед запуском создайте файл `.env` в корневой директории проекта:

```bash
cp .env.example .env
```

Заполните переменные в файле `.env`:

| Переменная | Описание | Обязательна? |
| :--- | :--- | :---: |
| `BYBIT_API_KEY` | API-ключ биржи Bybit | Да (или для расширенных лимитов) |
| `BYBIT_SECRET_KEY` | Секретный ключ биржи Bybit | Да |
| `ETHERSCAN_API_KEY` | API-ключ Snowtrace (Etherscan API для Avalanche) | Да |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота (получается через `@BotFather`) | Да |
| `TELEGRAM_CHAT_ID` | ID вашего чата или канала в Telegram (куда слать сигналы) | Да |

## 🚀 Развертывание и запуск

### Способ 1. Запуск через Docker Compose (Рекомендуемый)

Этот способ изолирует бота в контейнере, автоматически перезапускает его при сбоях и монтирует файл истории `trade_history.csv` на хост.

1. **Запустите контейнер в фоновом режиме:**
   ```bash
   docker compose up -d --build
   ```

2. **Просмотр логов работы бота:**
   ```bash
   docker compose logs -f
   ```

3. **Остановка бота:**
   ```bash
   docker compose down
   ```

4. **Перезапуск бота:**
   ```bash
   docker compose restart
   ```

---

### Способ 2. Запуск через чистый Docker CLI

1. **Сборка образа:**
   ```bash
   docker build -t avax_bot .
   ```

2. **Запуск контейнера:**
   - **Linux / macOS:**
     ```bash
     docker run -d \
       --name avax_bot \
       --restart unless-stopped \
       --env-file .env \
       -v "$(pwd)/trade_history.csv:/app/trade_history.csv" \
       avax_bot
     ```
   - **Windows (PowerShell):**
     ```powershell
     docker run -d `
       --name avax_bot `
       --restart unless-stopped `
       --env-file .env `
       -v "${PWD}/trade_history.csv:/app/trade_history.csv" `
       avax_bot
     ```

3. **Просмотр логов:**
   ```bash
   docker logs -f avax_bot
   ```

---

### Способ 3. Локальный запуск (без Docker)

Требуется установленный **Python 3.11+**.

1. **Создайте и активируйте виртуальное окружение:**
   - **Linux / macOS:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
   - **Windows (PowerShell):**
     ```powershell
     python -m venv venv
     .\venv\Scripts\Activate.ps1
     ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите бота:**
   ```bash
   python main.py
   ```

## 📊 Параметры стратегии (`config.py`)

Вы можете адаптировать стратегию под свои задачи, изменив параметры в [`config.py`](config.py):

| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `SYMBOL` | `'AVAX/USDT:USDT'` | Торговая пара деривативов на Bybit |
| `TIMEFRAME` | `'15m'` | Рабочий таймфрейм свечей |
| `PRICE_LOOKBACK_PERIOD` | `8` | Период свечей для расчета уровней ликвидности (Low/High) |
| `OI_LOOKBACK_PERIOD` | `6` | Период расчета скользящего среднего Открытого Интереса |
| `RISK_REWARD_RATIO` | `2.0` | Соотношение риск/прибыль (Take Profit = Entry ± Risk * 2.0) |
| `MAX_FUNDING_RATE_FOR_LONG` | `0.00015` | Максимальный фандинг для разрешения входа в LONG |
| `MIN_FUNDING_RATE_FOR_SHORT` | `0.00015` | Минимальный фандинг для разрешения входа в SHORT |
| `TRANSACTION_THRESHOLD_AVAX`| `10000` | Порог объема одной транзакции кита в WAVAX |
| `ONCHAIN_LOOKBACK_HOURS` | `24` | Глубина анализа ончейн-транзакций (в часах) |
| `CHECK_INTERVAL_SECONDS` | `60` | Интервал проверки рынка (в секундах) |
| `HEARTBEAT_INTERVAL_HOURS` | `6` | Интервал отправки сообщений о статусе работы бота |
